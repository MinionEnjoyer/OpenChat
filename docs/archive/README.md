# Documentation archive

This directory contains dated diagnostics, handoffs, proposals, completed work orders, and
retrospectives. They are retained as engineering evidence, not as instructions for the current
release.

Use the current [documentation index](../README.md) for setup, deployment, architecture, testing,
and integration guidance. Historical paths and links inside archived files intentionally reflect
the repository layout at the time they were written.

The archive is grouped as follows:

- top-level files: one-time handoffs, investigations, merge plans, and upstream proposals;
- `retrospective/`: batch and project retrospectives;
- `workorders/`: completed implementation work orders.
