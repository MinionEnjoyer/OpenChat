## Traps this codebase has, all of which fail SILENTLY

Every one reported success while doing nothing. This is the dominant failure
mode and it has cost more than every product bug combined.

- **`devctl verify --changed` was a no-op** for the life of the project. The
  pre-push hook ran it; no layer guard matched `--changed`, so all 11 gates
  skipped and it exited 0 in 0 seconds. Fixed 2026-07-28.
- **The trace gate accepted file paths as evidence.** Any `@satisfies` under
  `apps/mobile/e2e/flows/` counted as e2e proof whether or not the flow had ever
  run. Three agents independently found and took that shortcut. Now requires a
  passing receipt in `artifacts/e2e/receipts/`, written by the runner that
  actually executed the flow.
- **`expo prebuild` exits 0 when `pod install` fails.** Observed today. Grep the
  log; the exit code lies.
- **Gradle reports BUILD SUCCESSFUL without rebuilding.** Changing an env var
  does not invalidate its up-to-date check. Verify the artefact mtime AND hash.
- **Exit codes through pipes.** `cmd | tail` reports the pipe's status. Read `$?`
  on the line immediately after the command.
- **zsh does not word-split unquoted variables.** `for f in $LIST` iterates once
  over the whole string. Cost several wrong conclusions.
- **BSD vs GNU tools.** `grep "a\|b"` does not alternate in BSD; `sed \?` is
  literal; `timeout` does not exist on macOS.

## Process rules that earned their place

- **Perturb-and-restore before trusting any test.** Break the implementation,
  watch it go red, restore, watch it go green. A test never observed failing
  proves nothing. Verify the perturbation actually applied — one of mine silently
  matched nothing and I nearly reported the resulting pass as proof.
- **One requirement per agent.** Seven-requirement work orders step-capped twice
  and produced nothing. One-requirement orders finished 5/5 in nine minutes.
- **Dispatch agents with a tracked waiter.** `cmd &` inside a foreground call
  orphans them with no completion signal. That mechanism caused two 8-hour idle
  windows.
- **Never `npm install` in a worktree.** `node_modules` is one real directory
  symlinked into ~130 worktrees. Install only in `oc-integration/apps/mobile`.
- **`artifacts/trace/matrix.json` conflicts on every parallel merge** because it
  is a committed generated artefact. Resolve by regenerating. Better: gitignore
  it.
- **Check the dev API is up before blaming test failures.** 27 failures today
  were `node dist/main` not running. Nothing distinguishes "broken code" from
  "nothing listening on 3030".
